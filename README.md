# Ghulam Fatima | Full Stack Developer Portfolio

A responsive personal portfolio website built to showcase my skills, education, experience, services, and web development projects.

## Project Description

This portfolio website was developed to create a professional online presence and demonstrate my front-end and full-stack development skills.

The website follows responsive web design principles and includes interactive sections, project showcases, contact form validation, accessibility improvements, and basic SEO implementation.

## Features

* Responsive navigation bar
* Home/Hero section
* About section
* Skills section
* Services section
* Education section
* Experience section
* Projects showcase
* Project filtering
* Contact section
* Contact form validation
* Social media links
* Mobile navigation
* Responsive design
* CSS animations
* Accessibility improvements
* SEO metadata
* Semantic HTML structure
* Keyboard-friendly navigation

## Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/ghulam-fatima315/my-portfolio.git
```

### 2. Open the Project Folder

```bash
cd my-portfolio
```

### 3. Open the Project

This is a static HTML, CSS, and JavaScript website, so no additional package installation is required.

Open `index.html` in a web browser.

## How to Run

You can run the project directly by opening:

```text
index.html
```

in a browser.

You can also use the **Live Server** extension in Visual Studio Code for local development.
